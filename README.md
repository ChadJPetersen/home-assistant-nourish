# Nourish for Home Assistant

An experimental HACS-installable Home Assistant integration for your Nourish nutrition goals.

> **Experimental:** This is an independent community project, not endorsed by Nourish. It uses an undocumented endpoint and requires a user-provided access token. Tokens can expire, and Nourish's terms restrict automated access. Use only where authorized. Do not share tokens or cookies.

Features planned: daily sync at **11:56 PM Home Assistant local time**, a **Sync now** button and `nourish.sync_now` action, and read-only sensors for nutrient totals and goals.

Further documentation and integration files will follow in this repository.
